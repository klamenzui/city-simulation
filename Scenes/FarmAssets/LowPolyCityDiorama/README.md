# Low Poly City Diorama Farm Houses

Farm-house meshes copied from the user-provided local source:

`C:\dev\projects\Godot\assets\low_poly_city_diorama_scene.glb`

The source scenes use a shared texture and contain mesh coordinates from the
original diorama. `FarmHouse1.tscn` and `FarmHouse2.tscn` normalize their scale
and pivot so farm scenes can place them directly at ground level.

No license or attribution file was present in the source folder. Keep the
